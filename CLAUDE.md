# NoMoreBots — AI Content Filter Extension

## Overview
Chrome extension that filters AI-generated and low-quality content from Twitter/X and LinkedIn.

## Commands
```bash
npm run dev       # Dev server (Vite)
npm run build     # Production build
```

## Tech
- Vite + React 18 + TypeScript
- Chrome Extension (Manifest V3)
- Tailwind CSS
- Multi-AI classification (Anthropic, Google, OpenAI APIs)
